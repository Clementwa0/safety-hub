# Safety Hub

## Purpose
PPE commerce and business operations platform with a public storefront and protected Sentinel administration portal.

## Core Areas
- Products and categories
- Customers
- Inventory
- Quotations
- Orders
- Invoices
- Payments
- Analytics
- Administration

## Core Flows
```text
Storefront → Cart → Checkout → Order → Fulfillment
Quotation → Order → Invoice → Payment
```

## Goals
- Accurate inventory
- Reliable commercial relationships
- Secure administration
- Authoritative financial records
- Auditable operations
- Maintainable domain services

## Scope
Focus on inventory, orders, quotations, invoices, payments, authorization, auditability, testing, and correctness.

Do not rewrite the existing stack or add unrelated infrastructure.
